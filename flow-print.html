Rules, Cross-cutting & Page Map

Supporting detail for the module flow

Key rules agreed

  • Product Catalogue is the backbone. It holds specification, tube dimensions, capacity, laminate structure, BOM, routing, machines, standard wastage, QC parameters, packing, COA requirement, standard costing, version and past complaint / RCA / CAPA history. Selecting a catalogue product auto-fills estimation, BOM, routing and QC plan. A New / Custom Specification route exists for products not in the catalogue.
  • Material Requirement lives inside the Production Work Order — it is a tab, not a separate page.
  • Release is a button on Machine-wise Scheduling — no separate release screen.
  • The PWO raises the indent automatically under its own authority. The Purchase Order can only be created after the indent is approved.
  • Gate Entry before GRN is optional — controlled by a setting. If ON, material must be gated in before GRN; if OFF, GRN is made directly.
  • Three mandatory quality gates: RMQC on incoming material, IPQC during manufacturing (operation-specific, includes printing QC), FGQC after packing. No normal dispatch is allowed without FGQC approval.
  • Dispatch sequence is fixed: Production → Packing → FGQC → Delivery Note → COA → Dispatch.
  • COA is linked to Customer → Sales Order → Product → Production Order → Batch → FGQC, and carries test parameters, specification, actual results and QC approval.
  • Printing is an operation, not a purchase. Tracked per transfer: quantity sent, quantity received, good printed quantity, rejection, wastage, unprocessed quantity, printing status, printing cost, delay and the Company B transaction reference.

Cross-cutting — runs across every module

CAPA alert engine

Not a standalone module

The latest active CAPA / quality control appears automatically as an alert when a relevant transaction is performed. It can be linked to the Product Catalogue, material, supplier, BOM, routing, operation, machine, QC parameter, PWO, packing and dispatch.

A critical CAPA can be configured to block production, material issue, packing or dispatch until the required control is completed. Example: a past shoulder-leakage complaint surfaces that control on the relevant production operation.

Traceability — both directions

Needed if an RM batch is later found defective

Backward: Finished product → Production order → Operations → Raw material → Supplier → GRN → RMQC

Forward: Raw material batch → Production order → Finished product batch → Customer → Sales order → Dispatch
