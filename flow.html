Lamitube ERP — Process Flow & Page Map

Built from Company A's side · printing is an inter-company operation inside the Production Work Order · v2, revised per SRS

Revisions in this version

  • Material Requirement merged into the Production Work Order — no separate MRP page.
  • Release is a button on Machine-wise Scheduling — no separate Job Release page.
  • PWO auto-raises the Indent under its own authority. PO can only be created after the indent is approved.
  • Gate Entry before GRN is optional — a setting. If ON, material must pass the gate before GRN; if OFF, GRN directly.
  • Three quality gates fixed as RMQC → IPQC → FGQC, with FGQC after packing.
  • Added COA, Actual Costing vs Estimated, CAPA alert engine and Traceability.

Two companies, one flow

Company A

Main entity · our ERP

Enquiry, estimation, sales order, procurement, tube manufacturing, packing, dispatch, complaints. Caps and rims are bought ready-made from the market.

Company B

Separate GST · printing facility

Receives material from A, prints, does printing QC, sends printed material back. Treated as an operation inside the PWO, not an unrelated purchase.

Order-to-Cash Pipeline

1

Sales & Estimation

Module: Sales
Customer Enquiry Estimation catalogue product OR new / custom spec Quotation & Approval Sales Order

Cost build-up: Raw material + bought-out components + printing + manufacturing + packing + wastage + other direct costs → add margin → selling price. This estimate is stored and later compared against actual cost.

2

Production Work Order

+ BOM+ Material Requirement+ Auto Indent Module: Planning
Production Work Order BOM · routing · material requirement · raises indent automatically

The PWO is the central execution document: Customer → SO → Product → BOM → Routing → Material requirement → Production → Printing → QC → Packing → FG. Material requirement is a tab inside it, not a separate screen. The indent is raised under the PWO's own authority.

3

Scheduling

+ Release buttonModule: Planning
Machine-wise Scheduling Gantt · sequence · Release action

Release is an action on the schedule row — no separate release screen.

4

Procurement & Stock Allocation

Module: Purchase / Inventory
Indent Approval auto-raised by PWO · PO blocked until approved Purchase Order Gate Entry optional — only if setting is ON GRN Stock & Batch / Roll Tracking Material Issue / Allocation

Caps and rims are straight purchase items — no conversion. Gate Entry is config-driven: if enabled, material is gated in first and GRN picks it up from there; if disabled, GRN is made directly.

5

RMQC

Quality gate 1 of 3Module: Quality
RMQC / Incoming Inspection GRN → QC hold → Accepted / Rejected / Hold

Material sits on QC hold after GRN and cannot be issued until RMQC clears it.

6

Production & Inter-Company Printing

IPQC — gate 2 of 3Module: Manufacturing
Production Entry operation-wise · initial and remaining process Printing — Send to Company B Printing — Receipt & Reconciliation IPQC operation-specific, incl. printing QC WIP / Job Floor Status

Routing: initial tube process (A) → printing (B) → printed receipt (A) → remaining production (A) → cap / assembly → packing → FGQC. See the swimlane below.

7

Packing → FGQC → Dispatch

FGQC — gate 3 of 3Module: Dispatch
Packing FGQC after packing Delivery Note COA Dispatch & Invoice

Sequence is fixed: Production → Packing → FGQC → Delivery Note → COA → Dispatch. No normal dispatch is allowed without FGQC approval. COA is linked to Customer → SO → Product → PWO → Batch → FGQC and carries test parameters, specification, actual result and QC sign-off.

8

Actual Costing

Module: Costing
Actual Costing & Variance estimated vs actual · cost variance · estimated vs actual margin · order profitability

Built from actual consumption and actual processing cost: raw material, bought-out components, cap / rim, inter-company printing cost, manufacturing, packing, wastage, rejection, rework.

9

Post-Dispatch Exceptions

Module: Quality / Sales
Customer Complaint RCA CAPA & Closure Sales Return NCR

A complaint links back to Customer, Product, Batch, Sales Order, Delivery Note and PWO. CAPA carries immediate correction, corrective action, preventive action, responsible person, target date, evidence, effectiveness verification and closure.

Inter-company printing — swimlane

Reconciliation must balance — Material sent = Good output + Rejection + Wastage + Unprocessed return

Tracked per transfer: quantity sent, quantity received, good printed quantity, rejection, wastage, unprocessed quantity, printing status, printing cost, delay and the Company B transaction reference.

Cross-cutting — runs across every stage

CAPA alert engine

The latest active CAPA / quality control appears automatically as an alert on the relevant transaction — it is not a standalone quality module.

Product CatalogueMaterialSupplier BOMRoutingOperation MachineQC parameterPWO PackingDispatch

A critical CAPA can be configured to block production, material issue, packing or dispatch until the required control is completed. Example: a past shoulder-leakage complaint makes that control appear on the relevant production operation.

Traceability — both directions

Backward: Finished product → Production order → Operations → Raw material → Supplier → GRN → RMQC

Forward: Raw material batch → Production order → Finished product batch → Customer → Sales order → Dispatch

Needed when a raw-material batch is later found defective.
