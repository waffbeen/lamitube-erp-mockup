Process & Routing Master

Where a process is marked in-house or outsourced — nothing about outsourcing is hardcoded

The execution type on a process decides how the shop floor books it A process marked In-house books through Production Entry. A process marked Outsourced routes through Send Challan → Receipt & Reconciliation instead. Printing is outsourced today; any other process can be switched tomorrow without a code change.
